Grafana datasources#

This page lists the datasources the stack provisions in Grafana and the settings of the dashboard sidecar. Dashboards reference a datasource by its UID.

Provisioned datasources#

The stack provisions all datasources through grafana.datasources in the kube-prometheus-stack values. The datasource sidecar is disabled, and so is the chart’s default Prometheus datasource.

Datasource settings#

Thanos and Prometheus

timeInterval: 30s.

Alertmanager

implementation: prometheus and handleGrafanaManagedAlerts: false.

Loki

maxLines: 1000. The provisioning deletes any existing datasource named Loki in organization 1 before it creates the datasource with UID loki.

Tempo

timeout: 60. tracesToLogsV2 points at the datasource UID loki, filters by trace ID, and shifts the time range by one hour in each direction. tracesToMetrics points at the datasource UID thanos.

Dashboard sidecar#

The Grafana dashboard sidecar loads every ConfigMap that carries the label grafana_dashboard: "1".

Setting

Value

sidecar.dashboards.enabled

true

sidecar.dashboards.folderAnnotation

grafana_folder

sidecar.dashboards.provider.foldersFromFilesStructure

true

A dashboard ConfigMap with the annotation grafana_folder lands in the Grafana folder of that name. A dashboard ConfigMap without the annotation lands in the folder General.

Grafana server#

Setting

Value

server.domain

domains.grafana

server.root_url

domains.grafanaRootUrl, or https:// followed by domains.grafana when unset

Ingress

Created unless domains.grafanaIngress is false; class from domains.ingressClassName

Persistence

storage.grafana on the StorageClass from storage.className, access mode ReadWriteOnce
